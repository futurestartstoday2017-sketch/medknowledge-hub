# MedKnowledge Hub

製薬企業の製品情報・適応症・疾患情報などを一元管理し、検索・比較・学習するためのWebアプリです。
個人の学習用に作っているアプリで、**登録データはすべて架空のサンプルデータ**です。実在する製品の医学的情報は含みません。

> ⚠️ このアプリの内容は、診断や治療の代わりになるものではありません。

## 使用技術

- Python
- Streamlit（Webアプリの画面を作るライブラリ）
- SQLite（ファイル1つで動くデータベース）
- pandas（表形式のデータを扱うライブラリ）

## 起動方法（Windows / VS Code のターミナル）

```powershell
# 1. 仮想環境を作る（初回のみ）
python -m venv .venv

# 2. 仮想環境を有効にする（ターミナルを開くたびに実行）
.venv\Scripts\Activate.ps1

# 3. ライブラリをインストールする（初回のみ）
pip install -r requirements.txt

# 4. アプリを起動する（ブラウザが自動で開きます）
streamlit run app.py
```

止めるときは、ターミナルで `Ctrl + C` を押します。

データベースを初期状態に戻したいときは、アプリを止めてから `data/medknowledge.db` を削除し、もう一度起動してください。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `app.py` | 起動ファイル兼ホーム画面 |
| `db/database.py` | データベースへの接続・テーブル作成・サンプルデータ登録 |
| `db/queries.py` | データベースからデータを取り出す処理 |
| `data/sample_data.py` | 学習用の架空サンプルデータ |
| `data/medknowledge.db` | データベース本体（初回起動時に自動作成・Gitには含めない） |
| `requirements.txt` | 必要なライブラリの一覧 |
| `.streamlit/config.toml` | 画面のテーマ（色）の設定 |
| `.gitignore` | Gitに含めないファイルの一覧 |
| `CLAUDE.md` | Claude Code向けの作業ルール |
